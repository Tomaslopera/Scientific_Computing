# Computación Científica – Data Science & Machine Learning

Este repositorio contiene el material desarrollado durante la asignatura **Computación Científica**, enfocada en la **aplicación práctica de técnicas de Data Science y Machine Learning** para la resolución de distintos tipos de problemas reales.

A lo largo del curso se abordaron y resolvieron **casos de estudio completos**, cubriendo desde el análisis de los datos hasta la implementación y evaluación de modelos, todo esto implementando el modelo de solución **ASUM-DM**.

## Contenido del repositorio

El repositorio está organizado por carpetas según el **tipo de problema de aprendizaje automático** trabajado:

### 1. Agrupamiento (Clustering)
- Implementación de modelos de aprendizaje no supervisado.
- Análisis exploratorio de datos.
- Algoritmos como *K-Means* y otros métodos de agrupación.
- Interpretación de grupos y validación de resultados.

> Carpeta: `Agrupamiento/`

### 2. Clasificación
- Modelos de aprendizaje supervisado.
- Preprocesamiento de datos.
- Entrenamiento y evaluación de clasificadores.
- Métricas de desempeño como accuracy, precision, recall y confusion matrix.

> Carpeta: `Clasificacion/`

### 3. Regresión
- Modelos de regresión lineal y otros enfoques.
- Análisis de relaciones entre variables.
- Evaluación mediante métricas de error.
- Aplicación en problemas predictivos continuos.

> Carpeta: `Regresion/`

### ⏱️ 4. Series de Tiempo
- Análisis temporal de datos.
- Modelado y predicción de series de tiempo.
- Visualización de tendencias, estacionalidad y patrones.
- Casos aplicados a datos reales.

> Carpeta: `Series Tiempo/`

### 5. Sistemas de Recomendación
- Implementación de modelos de recomendación.
- Enfoques basados en contenido y/o filtrado colaborativo.
- Análisis de comportamiento y preferencias de usuarios.
- Uso de datasets reales.

> Carpeta: `Recomendacion/`

### 6. Datasets
- Conjunto de datos utilizados en los diferentes casos de estudio.
- Datos aplicados a problemas de clasificación, clustering,
  regresión, series de tiempo y recomendación.

> Carpeta: `Datasets/`

## Tecnologías y herramientas utilizadas

- **Python**
- **NumPy**
- **Pandas**
- **Matplotlib / Seaborn**
- **Scikit-learn**
- **Jupyter Notebook**
- Entornos locales (VS Code)

## Objetivo del repositorio

El objetivo principal de este repositorio es **demostrar la aplicación práctica de conceptos de computación científica y ciencia de datos**, utilizando modelos de Machine Learning para resolver diferentes tipos de problemas analíticos.

Además, funciona como:
- Material académico del curso
- Evidencia de aprendizaje
- Base para un portafolio en Data Science
